# DevOps Full-Stack Project

A comprehensive DevOps project demonstrating modern cloud-native application development and deployment practices.

## Architecture Overview

- **Frontend**: React.js with TypeScript
- **Backend**: Node.js/Express with TypeScript
- **Database**: PostgreSQL
- **Infrastructure**: Kubernetes on AWS
- **CI/CD**: GitHub Actions
- **Monitoring**: Prometheus + Grafana + ELK Stack
- **IaC**: Terraform

## Quick Start

1. Clone the repository
2. Copy `.env.example` to `.env` and configure
3. Run `docker-compose up` for local development
4. Access the application at `http://localhost:3000`
